==============================================================================
INTRODUCTION                                               *blink-cmp-ghostty*

blink-cmp-ghostty provides Ghostty configuration completions for blink.cmp. It
completes Ghostty configuration keys, enum values, and documentation extracted
from `ghostty +show-config --docs`.

==============================================================================
INSTALLATION                                  *blink-cmp-ghostty-installation*

With vim.pack (Neovim 0.12+): >lua
    vim.pack.add({
      'https://forge.barrettruth.com/barrettruth/blink-cmp-ghostty',
    })
< With luarocks: >sh
    luarocks install blink-cmp-ghostty
<

==============================================================================
CONFIGURATION                                *blink-cmp-ghostty-configuration*

Register the source with blink.cmp: >lua
    require('blink.cmp').setup({
      sources = {
        default = { 'ghostty' },
        providers = {
          ghostty = {
            name = 'Ghostty',
            module = 'blink-cmp-ghostty',
          },
        },
      },
    })
<
